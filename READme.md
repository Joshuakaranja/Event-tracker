# Event Tracker Project
A web-based event planner that allows users to create, share, and book upcoming events. Designed for general users to organize personal or public events easily.  
**By:** **Joshua Karanja**  
**Date:** May 1, 2025

## Description
The **Event Tracker Project** is a web-based platform designed to help users manage and track upcoming events, regardless of category—be it personal, professional, or public. Users can create their own events, share them with others, and book events created by others. One of its key features is a reminder system, which ensures that users don’t forget about important events, especially those they’ve personally scheduled. This solves a common problem of event mismanagement and forgetfulness by centralizing all event details in one easy-to-use interface.

## Setup/Installation Requirements
1. Clone or download the repository to your local machine.
2. Open the project folder.
3. Open the `index.html` file in any modern web browser.
